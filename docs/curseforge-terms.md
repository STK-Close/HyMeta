# What the CurseForge API terms say

Source: "CurseForge 3rd Party API Terms and Conditions", Overwolf Ltd, last modified August 14, 2024.
https://support.curseforge.com/en/support/solutions/articles/9000207405
Read on November 18, 2026, as a summary with quoted clauses. This is not legal advice.

| Topic | What the terms say | What it means for HyMeta |
| --- | --- | --- |
| Charging money | Nothing forbids a paid app. Clause 2.3: above a usage quota that Overwolf sets, continued use "may" need a written licence that "may contain payment requirements". | A paid tier is not ruled out, but Overwolf can ask for a licence or a fee as HyMeta grows. |
| Storing mod data | Clause 3.1 forbids to "save or cache any data obtained through the API". No exception is listed. | The plan to read the catalog weekly and keep the results conflicts with this as written. Needs written permission. |
| Competing | Clause 3.1 forbids building anything "that competes, directly or indirectly" with CurseForge. | Curated playpacks sit close to CurseForge's own modpacks. HyMeta sends every download back to CurseForge, which helps, but they decide. Needs written permission. |
| The key | Clause 2.2: the key is "non-transferable and may not be shared with any third party". | The key stays on HyMeta's server. It never goes inside the app. |
| Being cut off | Clause 8: Overwolf may end any app's access without cause on 30 days' notice. | A business risk to accept. |
| Mod files and logos | Not covered here. A separate "Mod Author Terms" page exists and has not been read yet. | Read before building the install feature. |
| Children | No rule for end users. | No change. |

## What to ask CurseForge for, in writing

1. That a paid subscription app is acceptable.
2. That HyMeta may store mod details on its own server and refresh them weekly.
3. That curated playpacks which link every download back to CurseForge are not treated as competing.
